# Мафия: установка и правила

Подготовлено 15 сентября 2026 года. Вторая игра открывается по адресу `/mafia/index.html`; на главной странице добавлена ссылка «Мафия · голос и видео». Используются прежний Supabase и существующая гостевая сессия. Discord не нужен.

## Что уже сделано

- 22 роли из вашего PDF, настройка состава на 5–24 игрока, случайная серверная раздача.
- Сервер автоматически проводит ночь, обсуждение, голосование, подсчёт, изгнание и проверку победы. Создатель комнаты играет на общих основаниях и не получает чужие роли.
- Камера обязательна для готовности, начала партии и отправки действий. При потере камеры живого участника сервер приостанавливает партию; после восстановления камер автоматическая пауза снимается. Ручную паузу снимает создатель.
- Днём живые участники видят и слышат друг друга. Ночью мафия и Лунатик переходят в общую закрытую комнату; остальные находятся в личных комнатах без чужого видео и звука. Погибшие изолированы от живой видеосвязи до конца партии и читают публичную хронику.
- На телефоне — вкладки «Стол», «Роль и ход», «Хроника». Выборы и результаты проверок доступны только владельцу роли.

В Supabase `dhuqvintfsmbigmvdvak` уже применена миграция `mafia_automatic_game_private_storage`, развёрнута Edge Function `mafia` и включён планировщик `mafia-automatic-phases`. Повторно запускать SQL на этом проекте не требуется. Файлы сайта в GitHub/Vercel этим обновлением автоматически не опубликованы.

## Подключение видеосвязи — необходимый следующий шаг

1. Создайте проект в [LiveKit Cloud](https://cloud.livekit.io/) и получите URL проекта, API key и API secret.
2. Откройте [Supabase → Edge Functions → Secrets](https://supabase.com/dashboard/project/dhuqvintfsmbigmvdvak/functions/secrets) и добавьте:

   | Имя секрета | Значение |
   | --- | --- |
   | `LIVEKIT_URL` | URL проекта вида `wss://your-project.livekit.cloud` |
   | `LIVEKIT_API_KEY` | API key этого проекта LiveKit |
   | `LIVEKIT_API_SECRET` | Соответствующий API secret |

   Секреты вводятся только в Supabase. Не добавляйте их в `mafia/config.js`, GitHub или сообщения. В `config.js` находится только существующий публичный ключ Supabase.
3. Загрузите файлы обновления в репозиторий с сохранением папок и дождитесь публикации Vercel. Существующие файлы заменяются целиком; новые добавляются. Текст кода к старым файлам дописывать не нужно.
4. Откройте `/mafia/index.html` по HTTPS, создайте комнату, соберите минимум 5 участников. Каждый нажимает «Подключить камеру» и «Я готов», после чего создатель начинает игру.

До подключения LiveKit можно открыть интерфейс и настроить лобби, но начать партию нельзя. Реальные звонки и переходы между комнатами ещё требуют проверки с вашим проектом LiveKit. Разрешение браузера на камеру и микрофон каждый игрок даёт самостоятельно.

## Правила спорных ситуаций

- **Маньяк** побеждает сразу после разрешения ночи или дневного изгнания, если вся мафия погибла, а он жив. Это ваше подтверждённое правило; ночью одновременные убийства сначала разрешаются полностью.
- **Шут** заканчивает партию своей победой только при фактическом дневном изгнании. Оправдание Судьи отменяет изгнание и победу Шута.
- **Потрошитель** побеждает один на один с обычным мирным. **Поджигатель** — один на один с представителем мирного города. По умолчанию оба также побеждают, оставшись единственным выжившим (`soloLastAlive`).
- Чёрные роли побеждают при равенстве или преимуществе над остальными живыми; Коханка выигрывает с мафией, но остаётся красной при проверке. Победа живого Маньяка после гибели всей мафии проверяется раньше остальных условий.
- Ночные действия выбираются одновременно. Грабитель блокирует первым; затем учитываются защиты, подставы, выстрелы и расследования. Погибший этой ночью успевает выполнить ранее выбранное действие. Поджог убивает всех ранее отмеченных живых, включая защищённых врачом.
- Дон определяет выстрел своим выбором; без его выбора нужен единственный лидер голосов клана. Голос Лунатика не учитывается. Дополнительный выстрел доступен клану после гибели Лунатика от атаки мафии.
- Ночь всегда состоит из основного окна и одинакового для всех заключительного окна. Результаты и погибшие появляются только на рассвете. Это не раскрывает мирным, понадобился ли мафии дополнительный выстрел.
- Доктор может лечить себя, но не одну цель две ночи подряд. Ограничение повторной цели также действует на Коханку, Крёстного отца и Грабителя; им нельзя выбирать себя.
- Дневной голос окончательный; можно воздержаться. При ничьей или отсутствии голосов никто не изгнан. Нельзя голосовать за себя, погибшего или обладателя публичного алиби.
- Новые игроки входят до раздачи ролей. Участник может восстановить свою сессию после перезагрузки. Выход в меню во время партии не удаляет персонажа: без его камеры игра ожидает возвращения.

## Проверки и границы защиты

Выполнены 33 проверки игрового движка и медиаправ, тесты настоящего Edge-обработчика с подменой внешних сервисов, проверки закрытого хранилища на рабочей базе внутри откатываемой транзакции, браузерные проверки «Мафии» на компьютере и телефоне и регрессия интерфейса «Бункера». Реальная Edge Function отклоняет неверные токены с HTTP 401; вызов планировщика через Vault получил HTTP 200.

Скрытое состояние хранится в `mafia_private.rooms`. У браузерных ролей нет прав на схему, таблицу и внутренние RPC. Edge Function проверяет сессию через `auth.getUser()` и выдаёт явный список разрешённых полей. Проверка JWT на шлюзе выключена только потому, что обработчик сам отдельно проверяет пользовательскую сессию и внутренний секрет планировщика.

Перед сменой фазы сервер отзывает прежние медиатокены с явным `revoke_token_ts`, затем сохраняет новую фазу. Выдача токена и смена состояния защищены арендой блокировки комнаты. Используется именно Cloud: [отзыв токенов LiveKit](https://docs.livekit.io/frontends/reference/tokens-grants/#token-revocation) недоступен в self-hosted-версии.

Проверяется опубликованный незаглушённый видеотрек с источником «камера». Это не распознавание лица и не доказательство присутствия человека: закрытый объектив или виртуальную камеру такая проверка не выявляет. Между фазами даются 20 секунд на переподключение; периодическая проверка работает примерно раз в 5 секунд. В приложении нет записи звонков, но запись средствами других участников и общение вне сайта технически не исключаются.

Аудитор Supabase сообщает [RLS без политик](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy) для закрытого хранилища: здесь это намеренный запрет прямого доступа игроков. Фактические права проверены SQL-тестом. Общие уведомления о гостевых сессиях относятся к существующему входу без регистрации; таблицы планировщика недоступны игрокам через схему `cron`.

## Файлы и повторное развёртывание

Для сайта нужны `index.html`, `js/games-nav.js`, папка `mafia/` и прежний `js/auth.js`. Остальные прежние файлы проекта сохраняются. Архив дополнения содержит полные версии изменённых файлов, исходники сервера, SQL и тесты. Полный архив проекта включает предыдущие исправления «Бункера».

Для другого Supabase-проекта сначала измените публичные настройки в `mafia/config.js` и адрес Edge Function в `supabase/mafia.sql`. Затем установите `mafia.sql`, разверните `supabase/functions/mafia/index.ts` вместе с `engine.mjs` и `media.mjs` с `verify_jwt=false` и добавьте секреты LiveKit. Встроенные серверные переменные Supabase предоставляет самостоятельно. Старый `release.sql` поверх текущего проекта повторно не выполняйте.

Команды проверок из корня проекта: `node tests/mafia-engine.mjs`, `node tests/mafia-handler.mjs` (Node 24), `node tests/mafia-browser.cjs` и `node tests/browser.cjs` (Playwright + Chrome). Для проверки базы выполняйте `tests/mafia-storage.sql` только внутри `BEGIN … ROLLBACK`. После правок клиентских файлов запускайте `node content/version-assets.cjs` для обновления версий ресурсов.
